# DEV-007 spec: testsite-email (Express, port 8890)

Files: testsite-email/{package.json,server.js,README.md,views/{join,verify,signin,profile}.html}
Run: `cd testsite-email && npm install && npm start`. Env: PORT, BASE_URL, SMTP_HOST(localhost), SMTP_PORT(1025), MAIL_FROM.

## Endpoints
- GET/POST /join (email, password>=8) -> inactive account, SMTP mail (link `BASE_URL/verify?token=..` + 6-digit OTP), 302 /verify?email=. SMTP down -> 503 re-render join with {{error}}, no account stored.
- GET /verify?token=T -> activates; GET /verify?email=E -> form. POST /verify (email, code) -> activates. Bad -> 400.
- GET/POST /signin (email, password): unverified -> 403 "Account not verified..."; bad creds -> 401; ok -> cookie `sid` (httpOnly), 302 /profile.
- GET /me -> 200 {authenticated:true,email} | 401. GET /profile (authed page, else 302 /signin). POST /signout.

## UI-002 handoff: overwrite views/*.html (placeholders exist). `{{key}}` is HTML-escaped substitution; missing -> empty. Keep form action/method/field names.
- join.html: vars error,email. POST /join: `email` (type=email, autocomplete=email, label), `password` (type=password, autocomplete=new-password, minlength 8, label).
- verify.html: vars error,message,email,verified("true" on success; emit e.g. data-verified). POST /verify: `email` (autocomplete=email), `code` (text, inputmode=numeric, autocomplete=one-time-code, 6 digits, label). Page must also render the token-link success/failure (message/error) with no form needed.
- signin.html: vars error,email. POST /signin: `email` (autocomplete=username), `password` (autocomplete=current-password).
- profile.html: var email; keep a visible "Signed in as {{email}}" success signal; sign-out is `POST /signout`.
- Error text should sit in role="alert" for accessibility.
