# UI-001 HTML run report (design_skill: hallmark, operational-report scope)
Entry: `authagent.report_html.render_report(dict|path) -> str`, `write_report_html(path) -> Path`, CLI `python -m authagent report <report.json>` (writes report.html next to it).
Reads real report.json keys only: url, host, status, started_at, finished_at, steps[] (step, pass, at, duration_s + step-specific extras, authenticated_html{label:{path,screenshot,title,bytes,authed_marker,no_leak}}), routes[{path,form}], artifacts[], failure{step,reason}|null.
Tokens (CSS vars): --paper #f6f5f1, --card #fff, --ink #1c1b19, --muted #6b675f, --rule #dcd8cf, --pass #1f7a4d / --pass-bg #e4f2ea, --fail #b3261e / --fail-bg #fbe7e5, fonts system-ui + ui-monospace (no CDN).
Components: header (host, status badge, times, total duration), failure banner, timeline (step card: status mark+text, name, time, duration, detail dl, evidence figures), routes table, artifacts list.

## Design checklist
- Status is never color-only: PASSED/FAILED text plus a mark glyph.
- One status badge in the header; failure banner directly under it when failed.
- Timeline cards: name left, status right; details as a small key/value list.
- Failed step gets red rule and its reason inline.
- Monospace for paths, times, codes; system sans for labels.
- Type scale tight: one headline, one label size, one body size.
- Contrast >= 4.5:1 for text on paper and on badge backgrounds.
- No italic headings, no emoji, no gradients, no decorative chrome.
- Screenshots in figure with hairline border, max-width 100%, captioned, lazy.
- Missing optional fields omitted, never shown as "None".
- Authenticated HTML is linked, never embedded.
- Single column under 700px; tables scroll in a wrapper, no page h-scroll.
- :focus-visible ring on links.
- All values HTML-escaped; no secrets re-introduced; no external requests.
